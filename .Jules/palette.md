## 2024-05-24 - Dynamic aria-expanded attributes on CSS hover menus
**Learning:** For menus or dropdowns in this application that are opened via CSS `:hover` states on a parent container (like `.space-options-dropdown` appearing when `.space-options-container` is hovered), mapping the `aria-expanded` attribute directly via click handlers isn't enough. We must dynamically map the `aria-expanded` state on the button to mouse and focus events (`mouseenter`, `mouseleave`, `focusin`, `focusout`) on the hover-activated parent container to ensure screen readers correctly announce the state change when the menu visually appears.
**Action:** Always add dynamic JavaScript event listeners to synchronize `aria-expanded` attributes on trigger buttons when implementing or modifying CSS hover-based menus.
