## 2024-04-13 - Dynamic ARIA Attributes for Custom Foldables

**Learning:** When building custom foldable elements like the pinned tabs chevron (`.space-toggle-chevron`) or folders (`.folder-toggle`) in this codebase, relying solely on adding/removing the `collapsed` CSS class causes the accessible state to fall out of sync with the visual state. This is particularly noticeable because these elements aren't using native `<details>`/`<summary>` elements. Furthermore, the `space-options` dropdown is visually triggered by CSS `:hover` on a container, which means screen readers get no programmatic notification that the dropdown is visible unless mouse/focus events actively update the button's `aria-expanded` state.
**Action:** When working with toggles or custom dropdowns that don't map directly to native HTML expandables, ensure JavaScript explicitly sets `.setAttribute('aria-expanded', 'true' | 'false')` alongside `.classList.toggle('collapsed')`. For hover-based dropdowns (like `.space-options-dropdown`), attach `mouseenter`/`mouseleave` and `focus`/`blur` event listeners to synchronize the `aria-expanded` attribute.
